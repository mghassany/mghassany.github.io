Lab on DBSCAN

Introduction

In this lab, you will apply DBSCAN (Density-Based Spatial Clustering of Applications with Noise) using scikit-learn. Unlike k-means or hierarchical clustering, DBSCAN does not require specifying the number of clusters in advance — it discovers clusters of arbitrary shape and automatically flags noise points (outliers) with the label -1.

DBSCAN has two hyperparameters:

  • eps (\(\varepsilon\)): the radius of the neighbourhood around each point.
  • min_samples: the minimum number of points required to form a dense region (core point).

Part 1 — Why DBSCAN? Motivation with Synthetic Data

Before working on a real dataset, we illustrate why DBSCAN matters using two classic synthetic datasets where k-means is known to struggle.

1. Generate two synthetic datasets — moons and circles — and visualize them side by side, colored by their true labels.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons, make_circles

X_moons, y_moons     = make_moons(n_samples=300, noise=0.07, random_state=42)
X_circles, y_circles = make_circles(n_samples=300, noise=0.05, factor=0.5, random_state=42)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].scatter(X_moons[:, 0],   X_moons[:, 1],   c=y_moons,   cmap="Set1", s=25)
axes[0].set_title("Two Moons — Ground Truth")
axes[1].scatter(X_circles[:, 0], X_circles[:, 1], c=y_circles, cmap="Set1", s=25)
axes[1].set_title("Concentric Circles — Ground Truth")
plt.suptitle("Datasets where k-means struggles", fontsize=13)
plt.tight_layout()
plt.show()

2. Apply k-means (\(k=2\)) and DBSCAN on both datasets. Arrange the results in a 2×2 grid (rows = method, columns = dataset). Comment on why DBSCAN handles these shapes better than k-means.

Note

In DBSCAN output, label -1 indicates noise points (outliers) that do not belong to any cluster. These are typically displayed in black when using cmap="Set1" or similar colormaps.

Part 3 — Comparison with k-means and Hierarchical Clustering

7. Using the number of clusters found by DBSCAN in question 5, apply k-means and agglomerative hierarchical clustering (Ward linkage) on the same scaled data. Plot all three results side by side for visual comparison.

8. Evaluate all three methods quantitatively using the Silhouette Score. For DBSCAN, exclude noise points from the computation. Display the results in a summary table and interpret them.

Tip

The Silhouette Score ranges from \(-1\) to \(1\). A higher value means points are well-matched to their own cluster and poorly matched to neighbouring clusters. A score near \(0\) indicates overlapping clusters, and negative values suggest misassignment.

Note that DBSCAN has an inherent advantage here: by excluding noise points, only the most coherent points enter the score computation.

9. Plot the Silhouette Score for k-means across \(k = 2, \ldots, 10\) on the Mall Customers data. At which \(k\) is the score maximized? Does it match the number of clusters found by DBSCAN?

10. Re-run all three algorithms using the best \(k\) identified in question. Plot the updated side-by-side comparison and the updated Silhouette Scores. Does the conclusion change?
