During this session we are going to analyse the Social_Network_Ads dataset 🔢. This dataset contains informations of users of a social network and if they bought a specified product. We are going to model the variable Purchased in function of Age and EstimatedSalary. We will fit using the models Logistic Regression, LDA, QDA, and Naive Bayes.

Logistic Regression

First, let’s do the pre-processing steps and fit a logistic regression model. Please read and understand very well the following code (read the comments!). Then copy what is necessary for your report (but remove my comments!) and execute it.

Tip

You can download the dataset from here 🔢.

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import scipy.stats as stats
import statsmodels.api as sm
from statsmodels.graphics.mosaicplot import mosaic
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, roc_curve, auc

# Loading the dataset.. I have putted it into a folder called "datasets"
# We'll use pandas to read the csv directly from the URL.
url = 'http://www.mghassany.com/courses/MLcourse/datasets/Social_Network_Ads.csv'
dataset = pd.read_csv(url)

# Describing and Exploring the dataset

print(dataset.info()) # to show the structure of the dataset (equivalent to str)
print(dataset.describe(include='all')) # will show some statistics of every column (equivalent to summary)
# Remark what it shows when the column is a numerical or categorical variable.
# Remark that it has no sense for the variable User.ID

# Boxplots using seaborn
plt.figure()
sns.boxplot(x='Purchased', y='Age', data=dataset, color="blue")
plt.title("Boxplot Age ~ Purchased")
plt.show()
# You know what is a boxplot right? I will let you interpret it.

plt.figure()
sns.boxplot(x='Purchased', y='EstimatedSalary', data=dataset, color="red")
plt.title("Boxplot EstimatedSalary ~ Purchased")
plt.show()
# Another boxplot

# Anova test, but we need to show the summary of 
# it in order to see the p-value and to interpret.
# In Python, we use scipy.stats.f_oneway
salary_purchased_0 = dataset[dataset['Purchased'] == 0]['EstimatedSalary']
salary_purchased_1 = dataset[dataset['Purchased'] == 1]['EstimatedSalary']

anova_salary = stats.f_oneway(salary_purchased_0, salary_purchased_1)
print(f"ANOVA EstimatedSalary ~ Purchased: F={anova_salary.statistic}, p-value={anova_salary.pvalue}")
# What do you conclude ?

# Now another anova test for the variable Age
age_purchased_0 = dataset[dataset['Purchased'] == 0]['Age']
age_purchased_1 = dataset[dataset['Purchased'] == 1]['Age']
anova_age = stats.f_oneway(age_purchased_0, age_purchased_1)
print(f"ANOVA Age ~ Purchased: F={anova_age.statistic}, p-value={anova_age.pvalue}")

# There is a categorical variable in the dataset, which is Gender.
# Of course we cannot show a boxplot of Gender and Purchased.
# But we can show a table, or a mosaic plot, both tell the same thing.
contingency_table = pd.crosstab(dataset['Gender'], dataset['Purchased'])
print(contingency_table)
# Remark for the function pd.crosstab(), that
# in lines we have the first argument, and in columns we have the second argument.
# Don't forget this when you use confusion_matrix() later!

# Mosaic plot
plt.figure()
mosaic(dataset, ['Purchased', 'Gender'], title="MosaicPlot of two categorical variables: Puchased & Gender")
plt.show()

# since these 2 variables are categorical, we can apply
# a Chi-square test. The null hypothesis is the independance between
# these variables. You will notice that p-value = 0.4562 which is higher than 0.05 (5%)
# so we cannot reject the null hypothesis. 
# conclusion: there is no dependance between Gender and Purchased (who
# said that women buy more than men? hah!)

chi2, p_val, dof, expected = stats.chi2_contingency(contingency_table)
print(f"Chi-square Test: p-value = {p_val}")

# Let's say we want to remove the first two columns as we are not going to use them.
# Python uses 0-based indexing, so Age, EstimatedSalary, and Purchased are columns 2, 3, and 4.
dataset = dataset[['Age', 'EstimatedSalary', 'Purchased']]
print(dataset.info()) # show the new structure of dataset


# splitting the dataset into training and testing sets
# We use scikit-learn's train_test_split. We use stratify=y to mimic R's sample.split target balancing.
X = dataset[['Age', 'EstimatedSalary']]
y = dataset['Purchased']

# CHANGE THE VALUE OF SEED. PUT YOUR STUDENT'S NUMBER INSTEAD OF 123.
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=123, stratify=y)

# scaling
# So here, we have two continuous predictors, Age and EstimatedSalary.
# There is a very big difference in their scales (units).
# That's why we scale them. But it is not always necessary.

sc = StandardScaler()
# Note that we fit AND transform the training set, but ONLY transform the test set
X_train_scaled = sc.fit_transform(X_train) 
X_test_scaled = sc.transform(X_test)

# logistic regression
# In Python, scikit-learn is standard for predicting, but statsmodels gives R-like summaries.
# Let's use statsmodels to get that nice summary() table first:
X_train_sm = sm.add_constant(X_train_scaled) # statsmodels needs a constant for the intercept
logit_model = sm.Logit(y_train, X_train_sm).fit()
print(logit_model.summary())

# For actual predictions in standard ML workflows, we usually use scikit-learn:
classifier_logreg = LogisticRegression(random_state=123)
classifier_logreg.fit(X_train_scaled, y_train)

# prediction

# this will predict the class
pred_glm = classifier_logreg.predict(X_test_scaled)

# predict_proba returns [prob_class_0, prob_class_1]. We want column index 1.
pred_glm_probas = classifier_logreg.predict_proba(X_test_scaled)[:, 1]
# This acts just like type="response" in R.

# Now let's assign observations to classes with respect to the probabilities
# np.where works exactly like ifelse in R
pred_glm_0_1 = np.where(pred_glm_probas >= 0.5, 1, 0)

# show some values of the vectors
print(pred_glm[:6])
print(pred_glm_0_1[:6])

# confusion matrix
# Sklearn's confusion_matrix takes (true_values, predicted_values)
cm = confusion_matrix(y_test, pred_glm)
print(cm)

# You can show the confusion matrix in a mosaic plot by the way, 
# but in Python, it's much more common to use a Seaborn heatmap!
plt.figure()
sns.heatmap(cm, annot=True, cmap="Blues", fmt="d")
plt.title("Confusion Matrix")
plt.xlabel("Predicted")
plt.ylabel("Actual")
plt.show()

# ROC
# we use the predicted probabilities not the 0 or 1
fpr, tpr, thresholds = roc_curve(y_test, pred_glm_probas)
roc_auc = auc(fpr, tpr)
print(f"AUC: {roc_auc}")

plt.figure()
plt.plot(fpr, tpr, color="green", label=f"AUC = {roc_auc:.2f}")
plt.plot([0, 1], [0, 1], color="black", linestyle="--") # abline(0,1) equivalent
plt.title("ROC Curve")
plt.xlabel("False Positive Rate")
plt.ylabel("True Positive Rate")
plt.legend(loc="lower right")
plt.show()

So now we have a logistic regression model stored in classifier_logreg. It is a model of Purchased in function of Age and EstimatedSalary.

5. Now let us plot the decision boundary obtained with LDA. You saw in the course that decision boundary for LDA represent the set of values \(x\) where \(\delta_k(x) = \delta_c(x)\). Recall that \[\delta_k(X) = x^T \Sigma^{-1} \mu_k - \frac{1}{2} \mu_k^T \Sigma^{-1} \mu_k + \log \pi_k\]

Here in our case, we have 2 classes (\(K=2\)) and 2 predictors (\(p=2\)). So the decision boundary (which is linear in the case of LDA, and line in our case since \(p=2\)) will verify the equation \(\delta_0(x) = \delta_1(x)\) Since we have two classes “0” and “1”. In the case of LDA this leads to linear boundary and is easy to be plotted. But in more complicated cases it is difficult to manually simplify the equations and plot the decision boundary. Anyway, we can use DecisionBoundaryDisplay from sklearn.inspection like following:

import matplotlib.pyplot as plt
import numpy as np
from sklearn.inspection import DecisionBoundaryDisplay

plt.figure(figsize=(8, 6))

# 1. Plot the decision boundary in one line
display = DecisionBoundaryDisplay.from_estimator(
    classifier_lda, 
    X_test_scaled, 
    response_method="predict",
    cmap="RdYlGn", 
    alpha=0.5,
    xlabel="Age",
    ylabel="Estimated Salary"
)


# 2. Scatter the real test set points on top
colors = np.where(y_test == 1, 'green', 'red')
display.ax_.scatter(X_test_scaled[:, 0], X_test_scaled[:, 1], c=colors, edgecolor='k', marker='o')

display.ax_.set_title('Decision Boundary LDA')
plt.show()

Extra: LDA from scratch

1. Now let us build a LDA model for our data set without using the lda() function. You are free to do it by creating a function or without creating one. Go back to question 6 and see what did you obtain by using lda(). It computes the prior probability of group membership and the estimated group means for each of the two groups. Additional information that is not provided, but may be important, is the single covariance matrix that is being used for the various groupings.

Tip

In LDA, we compute for every observation \(x\) its discriminant score \(\delta_k(x)\). Then we attribute \(x\) to the class that has the highest \(\delta\). Recall that

\[\delta_k(x) = x^T \Sigma^{-1} \mu_k - \frac{1}{2} \mu_k^T \Sigma^{-1} \mu_k + \log \pi_k\]

So to compute \(\delta_k(x)\) we need to estimate \(\pi_k\), \(\mu_k\) and \(\Sigma\).

Note that \[x=\begin{pmatrix} X_1 \\ X_2 \end{pmatrix}\] and here \(X_1\)=Age and \(X_2\)=EstimatedSalary.

So let us do it step by step, first we will do the estimates:

1.1 Subset the training set into two sets: class0 where Purchased = 0 and class1 where Purchased = 1).

1.2 Compute \(\pi_0\) and \(\pi_1\).

\[\pi_i = N_i / N, \,\, \text{where} \,\, N_i \,\, \text{is the number of data points in group i}\]

1.3 Compute \(\mu_0\) and \(\mu_1\). \[\mu_0 = \begin{pmatrix} \mu_0(X_1) \\ \mu_0(X_2) \end{pmatrix} \,\, \text{and} \,\, \mu_1 = \begin{pmatrix} \mu_1(X_1) \\ \mu_1(X_2) \end{pmatrix}\]

where, for example, \(\mu_0(X_1)\) is the mean of the variable \(X_1\) in the group \(0\) (the subset class0).

1.4 Compute \(\Sigma\). In the case of two classes like here, it is computed by calculating the following:

\[\Sigma = \frac{(N_0-1)\Sigma_0 + (N_1-1)\Sigma_1}{N_0+N_1-2}\]

where \(\Sigma_i\) is the estimated covariance matrix for specific group \(i\).

Remark: Recall that in LDA we use the same \(\Sigma\). But in QDA we do not.

1.5. Now that we have computed all the needed estimates, we can calculate \(\delta_0(x)\) and \(\delta_1(x)\) for any observation \(x\). And we will attribute \(x\) to the class with the highest \(\delta\). First, try it for \(x\) where \(x^T=(1,1.5)\), what is class prediction for this spesific \(x\)?
